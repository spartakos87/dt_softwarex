# Contributing

Bug fixes and documentation improvements are welcome. Before proposing a change, reproduce the issue with synthetic data only. Please include unit or integration tests where feasible, avoid generated credentials and personal data, and run the Python checks and frontend build described in `README.md`. Contributions to sensor/BIM mapping should document the mapping approach, naming requirements and failure modes. Do not change claims about forecasting, accuracy, latency or resource usage without providing a reproducible evaluation protocol and raw measurements.

Original authorship and the MIT notice must remain attributed; clean Git history does not negate attribution requirements.
